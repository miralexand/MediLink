# MediLink 信息科使用手册

面向信息科日常运维人员，介绍管理控制台与控制端的使用流程。

## 一、登录与口令

1. 浏览器打开 `http://<服务器IP>:21120/`（或控制端 exe 自动打开）；
2. 使用管理员账号登录；
3. 首次登录后，进入 **系统设置 → 修改管理员口令** 立即改密。

## 二、设备台账

### 自动登记
被控端安装后会自动上报设备 ID、计算机名、使用人、IP、操作系统等，并周期性心跳（在线状态 90 秒内有效）。

### 手动维护
在 **设备台账** 页可：
- 按设备 ID/计算机名/使用人/IP/科室关键字搜索；
- 按科室与在线状态筛选；
- 编辑科室、备注、标签（如“HIS 客户端”“PACS 工作站”）；
- 手动新增不在自动采集范围内的设备；
- 导出 CSV 台账，用于归档或导入其他系统。

> 建议科室字段使用统一命名（门诊、住院、检验科、放射科、收费处等），便于按科室批量筛选。

## 三、发起远程协助

1. 在设备台账找到目标终端（可按使用人/科室/计算机名搜索）；
2. 点击 **远程协助**：
   - 系统自动创建审计记录并返回设备 ID 与无人值守密码；
   - 控制端会调用本机 RustDesk 发起连接，并自动填充密码；
3. 若被控端启用“连接需确认”，终端用户会看到确认提示；
4. 协助完成后点击 **结束会话**，记录本次时长。

> 建议默认只读查看，确需操作时再向用户申请控制权限。

## 四、无人值守密码

- 每台被控端由服务端生成独立无人值守密码，加密存储；
- 在台账点击 **换密码** 可轮换，被控端下次心跳后生效；
- 建议对服务器、收费、检验等关键终端定期轮换。

## 五、会话审计

- **会话审计** 页记录登录、发起协助、结束会话、改密、改设置等行为；
- 支持关键字查询与 CSV 导出；
- 在系统设置中可调整留存天数并清理超期日志；
- 审计日志建议定期导出归档，满足等保留存要求。

## 六、批量部署建议

### 方式一：静默安装包（推荐）
```powershell
MediLink-Agent-Setup-1.0.0.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART `
  /SERVER=http://10.0.0.10:21120 /KEY=<注册密钥> /DEPARTMENT=<科室>
```

### 方式二：PowerShell 轻量版
```powershell
.\install-agent.ps1 -Server http://10.0.0.10:21120 -EnrollmentKey <密钥> -Department 门诊
```

### 方式三：GPO / SCCM
1. 将安装包放入分发共享；
2. 通过组策略“计算机配置 → 软件安装”或 SCCM 推送；
3. 参数按上方静默示例填写。

## 七、系统设置项

| 设置 | 说明 | 建议 |
|---|---|---|
| 站点名称 | 控制台标题展示 | 填写医院名称 |
| ID / 中继服务器 | RustDesk 接入地址 | 与 .env 一致 |
| RustDesk Key | 服务端公钥 | 部署后从 `id_ed25519.pub` 获取 |
| 注册密钥 | 被控端接入校验 | 生产必填强随机串 |
| 允许自动注册 | 是否接受新被控端 | 完成部署后可关闭 |
| 连接需确认 | 被控端是否弹窗确认 | 生产建议开启 |
| 默认只读 | 连接默认权限 | 建议开启 |
| 审计留存天数 | 日志保留时长 | ≥180 天 |

## 八、日常巡检清单

- [ ] 检查服务端容器与端口存活；
- [ ] 查看在线/离线设备数量，排查异常离线终端；
- [ ] 检查审计日志，关注非工作时间的连接记录；
- [ ] 定期备份 `data/` 目录并转存灾备；
- [ ] 清理离职、报废设备台账。
